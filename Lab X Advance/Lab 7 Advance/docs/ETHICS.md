# แนวทางจริยธรรมและกฎหมายในการ Web Scraping

1. **เคารพ robots.txt**: ตรวจสอบ `https://[domain]/robots.txt` ก่อน scrape ทุกครั้ง และปฏิบัติตามกฎ
2. **ตรวจสอบ Terms of Service (ToS)**: หากไซต์ห้าม scraping อย่างชัดเจน การ scrape ถือเป็นการละเมิดสัญญาและอาจถูกดำเนินคดี
3. **สุภาพ: Rate Limiting และ Delays**: หน่วงเวลา 2-5 วินาทีระหว่างการโหลดหน้า และหลีกเลี่ยงการส่ง request พร้อมกันจำนวนมาก
4. **ระบุตัวตน (User-Agent)**: ใส่ User-Agent ที่ระบุตัวตนของ scraper ให้ชัดเจน
5. **ไม่ปลอมตัวหรือซ่อนตัว**: ทำงานอย่างโปร่งใสและไม่มีเจตนาร้าย
6. **การใช้ข้อมูลและลิขสิทธิ์**: เนื้อหาที่ scrape มามักมีลิขสิทธิ์ ห้ามเผยแพร่ซ้ำโดยไม่ได้รับอนุญาต
7. **ข้อบังคับทางกฎหมายและความเสี่ยง**: การละเมิดสัญญา, trespass to chattels, การละเมิดลิขสิทธิ์ และการละเมิดความเป็นส่วนตัวของข้อมูล

**สรุป:** ทำงานอย่างมีความรับผิดชอบ สุภาพ และถูกกฎหมายเสมอ หากไม่แน่ใจให้ขออนุญาตจากเจ้าของเว็บไซต์ก่อน
